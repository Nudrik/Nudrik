### 🩸 [Smart Blood Bank Management System](https://smart-blood-bank-ln0b.onrender.com/)
> **Real-Time Healthcare Coordination & Blood Donor Platform**

[![Visit Live Production](https://img.shields.io/badge/Live_Production_App-Visit_Render_Deployment-e63946?style=for-the-badge&logo=render&logoColor=white)](https://smart-blood-bank-ln0b.onrender.com/)

An intelligent full-stack healthcare platform engineered to streamline blood donor-recipient coordination, real-time inventory management across all blood groups (A+, B+, O+, AB+, etc.), emergency request dispatching, and multi-portal hospital administration.

- **Live Deployment:** Fully deployed and active on [Render Cloud](https://smart-blood-bank-ln0b.onrender.com/) with high availability.
- **Real-Time Inventory:** Instant stock level tracking across all blood groups with automated shortages and emergency warnings.
- **Smart Matching Engine:** Algorithmic donor-recipient compatibility calculation with proximity notifications.
- **Multi-Role Authentication:** Dedicated dashboards for Hospital Administrators, Registered Donors, and Patients with stateless JWT authorization.
- **Resilient Microservices:** RESTful API backend with schema validation, sanitized request handling, and optimized database queries.
